## 六、当前阶段形成的统一规则

经过本阶段调整，已经基本形成以下规则：

### 1. 首屏列表参数进入方式

- 优先使用 `default-params`
- 页面尽量不要在 `mounted / ready` 里再手动补刷

### 2. 列表刷新入口

- 优先使用 `reload()`
- 页面尽量减少直接调用 `getList()`

### 3. 页面与公共组件边界

- 页面尽量不直接操作 `tableState`
- 页面尽量不自定义一套 `SearchTable` 暴露协议

### 4. 用户成功反馈时机

- 成功提示尽量在列表刷新完成后给出
- 弹窗关闭、刷新、提示的顺序保持稳定
