## 使用方式（改造时）

1. 确认本批属于 [重构实施批次计划](./重构实施批次计划.md) 的哪一批。  
2. 在 [模块级待办](./模块级待办清单与验收标准.md) 勾选本次范围。  
3. 改造完成后写入 [阶段性已完成改动说明](./阶段性已完成改动说明.md)，并把对应待办改为 `[x]`。  
4. 若涉及页面/API 迁移，同步更新页面快速定位表。
