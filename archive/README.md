# Legacy Archive

`archive/operationView-legacy` 保存旧运营端页面源码，仅用于历史留档与必要时回溯。

`archive/api-operationView-legacy` 保存旧 `operationView` 独占、现已停用的历史 API 实现。

`archive/managementView-legacy` 保存代理端迁移到 `src/management` 前的旧页面源码。

`archive/api-managementView-legacy` 保存代理端迁移到 `src/api/management` 前的旧平铺 API 实现。

- 当前正式运营端源码目录：`src/operation`
- 当前正式运营端 API 目录：`src/api/opertion`
- 当前正式代理端源码目录：`src/management`
- 当前正式代理端 API 目录：`src/api/management`
- 旧运营端已停止参与当前路由、构建、类型检查与日常开发
- 旧代理端已停止参与当前路由、构建、类型检查与日常开发
- 如需参考旧实现，请直接查阅归档目录，不要重新从业务代码引用
